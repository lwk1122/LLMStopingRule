# Source and adaptation map

Paths below refer to the original research archive, not runtime dependencies of
this package.

| Release file | Original source | Adaptation |
|---|---|---|
| `analyze.py` | `paper/More_Attempts_or_Better_Selection/minor_revision_20261009/analyze.py` | Load normalized observations and write to `results/`; retain replay, joint bounds, cohort handling and tie bootstrap calculations |
| `reproduce.py` | Current raw-record verifier, joint analysis and `analyze_revision_controls.py` | Compact release verification, simple-control replay, and table/trajectory exports |
| `editing/exact.py` | `exp/scripts/jss_round8/editor.py` | Unchanged |
| `editing/matching.py` | `exp/scripts/jss_round13/editor.py` | Replace the project-local editor import with `.exact` |
| `editing/vendor/editblock_coder.py` | Aider v0.86.2, `aider/coders/editblock_coder.py` | Unchanged upstream source; the adapter loads seven named matching functions via Python AST |
| `tests/test_core.py` | Earlier policy and editor tests | Standard-library unittest tests, plus explicit independent-grade isolation and atomic multi-edit tests |

The upstream Aider version is pinned to commit
`253f0368b873ba30d8ee26e463718f0c03614ddf`.
Source: https://github.com/Aider-AI/aider/blob/v0.86.2/aider/coders/editblock_coder.py

The data export checked patch hashes against proposal and grading references,
grading-log hashes, provider token totals, visible check outcomes, and the
original evaluation labels. It derived `changed` from consecutive patch hashes
where historical proposals omitted that field and checked it against explicit
values wherever present.

`reference/output_hashes.json` contains the original hashes of eight complete
analysis outputs. Reproduction compares regenerated files with these original
hashes, not with baselines regenerated by the release code.

`MANIFEST.json` covers analysis code, input data, expected results, and the vendor
license. Maintainer documentation and Git settings are excluded so links and
repository instructions can be updated. The manifest checks file integrity,
not scientific validity, and does not replace independent replication.
